# SwagX Panel

Secure Minecraft management website. Deploy with Render Free using Node.js 22.22.2, `npm ci --omit=dev` and `npm start`.

The local SwagX agent retains all user accounts, passwords, Minecraft files and backups. Set AGENT_TOKEN and BRIDGE_SECRET only in private hosting environment variables. Never commit local agent configuration.

Run `npm test` to validate the portable encrypted relay. Read README.txt for operating details and free-plan limitations.
