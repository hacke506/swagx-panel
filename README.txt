SwagX — подготовка к бесплатному Render

Этот пакет готовит сайт для Node.js-хостинга вместо chatgpt.site. Пока он НЕ опубликован на Render: для публикации нужно подключение к аккаунту Render и источник кода.

Команды: npm ci --omit=dev; npm test; npm start.
Используется бесплатный тариф Render Free, настройки описаны в render.yaml.
Переменные AGENT_TOKEN и BRIDGE_SECRET задаются приватно на хостинге. Они должны совпадать с секретами локального агента в SwagX-Panel/data/hosted.json. Этих секретов в архиве нет.
Render сам задаёт RENDER_EXTERNAL_URL и PORT.

Сайт использует исходящие HTTPS-подключения агента. Новые пользователи не получают права автоматически. Сохранены шифрование очереди, проверка прав, защищённые cookies, CSRF и ограничения запросов.
Пользователи, пароли, Minecraft и резервные копии остаются на твоём компьютере. На Render хранятся только временные запросы и зашифрованные части ответов. Они могут пропасть при перезапуске хостинга; готовые действия не повторяются автоматически.
После получения адреса Render нужно обновить origin в конфигурации локального агента и перезапустить Start-Hosted.cmd. При смене домена потребуется войти заново.

Render Free имеет ограничения: 750 часов на рабочее пространство в месяц и остановка сервиса после 15 минут без входящего трафика. Следующее открытие может занять около минуты. Бесплатный тариф не даёт гарантии бесперебойного доступа.
Руководство: https://render.com/docs/free
Не подключайте платные ресурсы. Не публикуйте data/hosted.json, серверные файлы и ключи в репозитории.
